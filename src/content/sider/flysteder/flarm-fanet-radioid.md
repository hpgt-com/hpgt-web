**Hva er RadioID?** En unik ID som varioen din sender via FANET/FLARM. Den gjør at andre piloter kan se deg på skjermen.

**Buddy-liste:** Importer ID-ene i varioen din for å se navnene til medpiloter direkte, ikke bare anonyme prikker.

**Offentlig info:** ID-ene er allerede synlige på [OGN](http://www.glidernet.org) og lignende nettverk under flyging.

> **Stealth-modus:** Noen piloter velger å ikke vises på offentlige sporingsnettverk. Ønsker du å stå utenfor dette registeret, ta kontakt med admin.

## Legg til eller oppdater din ID

Send navn, vario og RadioID til [post@hpgt.com](mailto:post@hpgt.com?subject=FLARM%2FFANET%20RadioID%20registrering), så oppdateres listen.

## Hvordan finne din RadioID

| Vario | Hvor |
|---|---|
| XCTracer Maxx / Maxx 2 | Innstillinger → System → FANET → Device ID (6 hex-tegn, f.eks. 200B6A) |
| Oudie / Oudie Omni | Settings → FLARM → FLARM ID |
| XCTrack (Android) | Innstillinger → Kommunikasjon → FANET → RadioID |
| Skytraxx | Setup → FANET → Own ID |
